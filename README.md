# PVZQoL2 · 重植版花园助手

适用于 **Plants vs. Zombies: Replanted（植物大战僵尸：重植版）1.5.1469 x64** 的 Windows 便携插件。自动拾取保留原生动画，花园耗材用完按商店价格补购，还可以持续喂智慧树。

**[下载便携版](https://github.com/mashdd/PVZQoL2/releases/latest)** · [配置与常见问题](#配置) · [构建源码](#从源码构建)

> 自动喂树、干草叉及耗材补购默认开启，会消耗存货和游戏金币。持续喂树没有高度上限；不需要时请取消勾选。v0.5.0 新增花园自动化已通过离线逻辑检查，尚未完成完整的游戏内实机验证。

## 功能

| 功能 | 行为 |
| --- | --- |
| 自动拾取阳光 | 调用游戏自身的拾取流程，保留飞行动画，可调等待帧数 |
| 自动拾取金币、钻石 | 保留原生拾取与结算动画，独立开关 |
| 花园卷心菜彩蛋外观 | 仅花园内使用游戏已有的彩蛋模型，重新进入花园生效 |
| 干草叉自动补购 | 支持的关卡开始时，库存为零才购买；正常扣金币、消耗次数 |
| 持续喂智慧树 | 仅在智慧树界面，每 3 秒尝试一次原生施肥，保留生长动画 |
| 花园肥料自动补购 | 用完补一包，每包 5 份 |
| 杀虫剂自动补购 | 用完补一包，每包 5 份 |
| 树肥自动补购 | 已拥有智慧树时，用完补一份 |

耗材仅在花园或智慧树界面补购，按商店当前价格扣金币，金币不足时跳过。花园自动化在暂停、商店或游戏弹窗打开时等待；自动喂树还会等待玩家放下手持工具。购买和喂树会通过游戏原生流程保存结果。

当前版本没有僵尸血条、无限阳光、直接修改金币或解锁存档的功能。

## 下载与安装

1. 在 [Releases](https://github.com/mashdd/PVZQoL2/releases) 下载 `PVZQoL2-v0.5.0-win-x64.zip`。普通玩家无需下载 `Source code`。
2. 正常退出游戏和旧助手。首次使用建议备份自己的游戏存档。
3. 解压，将整个 `PVZQoL2` 文件夹放到 `Replanted.exe` 所在目录：

   ```text
   游戏目录/
   ├─ Replanted.exe
   ├─ GameAssembly.dll
   └─ PVZQoL2/
      ├─ PVZQoL2.exe
      ├─ PVZQoL2.dll
      ├─ settings.ini
      └─ 使用说明.txt
   ```

4. 双击 `PVZQoL2.exe`，按需取消功能勾选，再点击「启动游戏并启用」。助手界面为中文；它不会修改游戏本身的语言。
5. 游玩期间保留助手运行。关闭对应勾选即可停止对应功能；关闭助手会停用自动功能。

也可以使用 `PVZQoL2.exe --auto` 启动助手并自动连接游戏。请不要同时加载旧版助手或多个具有相同功能的插件。

### 版本要求

- Windows x64；启动器依赖 Windows 的 .NET Framework 4.x 和 Windows Forms。
- 仅适配重植版 **1.5.1469 x64**，不适用于 2009 原版、年度版或其他模组版本。
- 启动器会校验 `GameAssembly.dll`，仅接受下列 SHA-256：

  ```text
  E7333EAF87996FA44B4A3526986272319B7D01F7ACDBCFF52451652F61CEB696
  ```

游戏更新或二进制不同会拒绝加载。请勿通过删除校验来尝试不受支持的版本。仓库不包含游戏本体、游戏资源或存档。

## 配置

界面选项会自动保存到助手同目录的 `settings.ini`，`1` 为开启，`0` 为关闭。离线修改配置前先关闭助手。

| 键 | 默认值 | 说明 |
| --- | --- | --- |
| `sun` | `1` | 自动拾取阳光 |
| `money` | `1` | 自动拾取金币、钻石 |
| `delay` | `20` | 拾取等待帧数，界面范围 5–120；原速下 25 帧约 0.5 秒 |
| `gardenCabbage` | `1` | 花园卷心菜彩蛋模型 |
| `autoRake` | `1` | 无干草叉时付费补购 |
| `autoFeedTree` | `1` | 持续喂智慧树 |
| `autoFertilizer` | `1` | 自动补购花园肥料 |
| `autoBugSpray` | `1` | 自动补购杀虫剂 |
| `autoTreeFood` | `1` | 自动补购树肥 |

**卷心菜外观是运行时替换，不能永久写入存档。** 每次需要该外观时都要启用助手。喂树和购买已经产生的进度、消费不会因关闭助手而撤销。

## 更新与卸载

更新时正常退出游戏及助手，再替换 `PVZQoL2` 文件夹内的程序。想保留偏好时可先备份 `settings.ini`。

卸载时正常退出游戏及助手，删除整个 `PVZQoL2` 文件夹即可。插件不修改游戏二进制、不安装服务、不注册自启动。运行时会在自己的目录生成 `native.log` 与 `diagnostics.json`，排查后可删除。

## 常见问题

- **版本不匹配：** 核对上述版本与哈希；文件夹名相同不代表程序相同。
- **开关打开但无效果：** 确认助手已经连接；花园功能需要进入相应界面，金币不足不会补购。升级 DLL 后必须完整退出并重启游戏。
- **外观没变化：** 启用后退出并重新进入花园，仅卷心菜适用。
- **想停止花钱：** 取消「持续自动喂智慧树」以及相应的自动购买开关。
- **安全软件提示：** 插件使用 DLL 注入和函数挂钩，发行文件未数字签名。可检查源码、自行构建或提交文件给安全软件厂商复核；不要关闭整机防护。
- **异常或退出卡住：** 停止使用，记录游戏版本、复现步骤和助手状态，在 Issues 反馈。提交日志前检查并移除其中的个人目录信息。

## 从源码构建

构建环境：Windows x64、[Zig 0.13.0](https://ziglang.org/download/0.13.0/)、Windows .NET Framework C# 编译器。MinHook 1.3.4 所需源码已放在 `third_party/minhook`。

在项目根目录的 PowerShell 中运行：

```powershell
.\build.ps1 -Zig '路径\zig.exe'
```

输出 `PVZQoL2.exe` 和 `PVZQoL2.dll`。将二者和 `settings.ini` 放进游戏目录下的 `PVZQoL2` 文件夹。构建脚本不会启动或连接游戏。

```text
Launcher.cs           中文 WinForms 启动器、版本校验及设置
native.c              游戏线程中的拾取、花园、智慧树与退出处理
third_party/minhook/  函数挂钩依赖
verification/         使用模拟游戏对象的离线逻辑检查源码
provenance.json       适配版本、工具链及发行文件哈希
dist/PVZQoL2/         与发行包一致的便携文件
```

### 验证范围

此前本地离线检查通过了 20 个花园场景和 10 个干草叉场景，覆盖扣款、库存、余额不足、失败回滚及暂停条件，不访问真实游戏或存档。早期版本的原生拾取、正常退出和卷心菜外观经过用户实机确认。**v0.5.0 新增喂树和耗材补购尚未完成游戏内实机验证**，离线通过不等于所有游戏场景兼容。
